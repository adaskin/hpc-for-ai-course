## Quick Start

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Generate Your Dataset

You must choose and prepare your own dataset (see project guidelines).
Each script generates synthetic test data if embeddings are not found,
but you should replace this with your real data.

### 3. Run Each Phase

```bash
# Phase 1: Baseline & Profiling
cd phase1_baseline
python naive_search.py          # implement the TODOs first!
python profiling_template.py    # profile your implementation

# Phase 2A: Sparse vs Dense
cd ../phase2_matrix_ops
python sparse_dense_compare.py  # implement dot products, compare representations

# Phase 2B: SVD
cd ../phase2_matrix_ops
python svd_power_iteration.py   # implement power iteration, compare methods

# Phase 2C: Vectorisation
cd ../phase2_matrix_ops
python vectorise_vs_loop.py     # implement 4 versions, benchmark

# Phase 3: Parallelism (choose at least 3)
cd ../phase3_parallelism
python thread_pool_search.py    # threads + NumPy
python process_pool_search.py   # processes + pickling demo
python async_search.py          # asyncio for I/O simulation
python ray_search.py            # Ray tasks/actors
```

## Using benchmark_utils.py

```python
from benchmark_utils import benchmark, plot_speedup, print_comparison_table

# Time your function
result = benchmark(my_function, arg1, arg2, warmup=3, runs=5)
print(f"Mean: {result['mean']:.4f}s")

# Compare versions
results = {
    "baseline": benchmark(baseline, args),
    "optimised": benchmark(optimised, args),
}
print_comparison_table(results, baseline_name="baseline")
plot_speedup(list(results.keys()), [r['mean'] for r in results.values()], "baseline")
```

## Tips

1. **Start small:** Use 1,000 documents for development; scale to 20,000 for benchmarks
2. **Always warmup:** Critical for Numba JIT (first call compiles)
3. **Run multiple times:** Use `runs=5` minimum; report mean and std
4. **Verify correctness:** Check that optimised versions return same results as baseline
5. **Save raw data:** Use `save_results_csv()` for easy report inclusion
6. **Plot with captions:** Every figure needs a conclusion caption, not just a description

## Common Issues

**"Implement this yourself!" errors:**  
These are intentional. Fill in the `TODO` sections in each file.

**Numba compilation is slow:**  
Expected on first call. Use `warmup=3` in `benchmark()`.

**Ray/Dask not installed:**  
Install with `pip install ray dask[complete]` or skip those strategies.

**Out of memory:**  
Reduce corpus size or embedding dimension. Project works with 5K x 128 on any laptop.

**Plots not saving:**  
Ensure write permissions. Check that `matplotlib` is installed.
