# Week 5 examples

Slides: `../05distributed-parallelism.md` (Marp; one combined file, Parts I-VII. Examples marked 'extra' are optional or for Project 1 / homework).
Figures: `../img/w05-*.svg`, regenerated by `python make_figures.py` (`--png DIR` for previews).

## Setup

```bash
pip install "dask[complete]" ray numpy pandas matplotlib
# Colab, for dask.visualize in example 02:
apt-get install graphviz
```

Run everything once before class (about 5-10 min on 2 cores) and keep `example_results.txt`:

```bash
python run_all_examples.py            # or: --only core | dask | ray
```

Each example checks its own answer against a serial version (`corpus.py`), so PASS means the result is correct.
Always keep distributed code inside `if __name__ == "__main__":`.
